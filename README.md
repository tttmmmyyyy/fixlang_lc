# Fix language client

The client of language server protocol for [Fix lang](https://github.com/tttmmmyyyy/fixlang) in VSCode.

This extension also provides syntax coloring through the language server's **semantic tokens** (which requires the `fix` compiler to be installed). If you use this extension, you do **not** need the separate [Fix syntax highlight](https://marketplace.visualstudio.com/items?itemName=tttmmmyyyy.fixlangsyntax) extension, which colors via a static TextMate grammar instead.
