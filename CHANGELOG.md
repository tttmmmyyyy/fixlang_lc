# Change Log

## [0.3.0] - 2026-05-03

- Merge syntax highlighting (formerly `tttmmmyyyy.fixlangsyntax`) into this extension and rename it to `fixlang`. The previous `fixlang-language-client` and `fixlangsyntax` extensions are now deprecated.
- Rename the configuration key `fixLanguageClient.compilerCommand` to `fixlang.compilerCommand`. Users who customized the previous setting need to set the new key.

## [0.2.0] - 2024-12-12

- Add `fixLanguageClient.compilerCommand` setting to specify the Fix compiler command.

## [0.1.0] - 2024-09-09

- Initial release.
